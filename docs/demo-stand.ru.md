## Об обработке

Это изображения для оформления, полученные из фотографий владельца с помощью
AI-ретуши. Убраны фон, посторонние кабели и провода за правым краем корпуса из
LEGO. IP-адрес скрыт, остальные данные дисплея видны. Для верхнего ракурса также
скорректированы поворот и перспектива.

Генеративная обработка изменила часть мелких надписей, символов дисплея и деталей
сборки. Для подключения, обозначений выводов и настройки модулей используйте
[схему, сверенную с исходниками](wiring.ru.md). Фотографии не являются распиновкой
или подтверждением совместимости с Samsung Wallet, работы физического привода
замка либо сертификации Aliro.

На сайте показан вид сверху; оба ракурса доступны на этой странице. WebP уменьшает объём загрузки, PNG сохраняет
прозрачность для повторного использования. Исходные фотографии стола, сетевые
адреса, резервные копии устройства и прошивки в публичный репозиторий не добавлялись.
