# Сайт Aliro Mayday

[English](README.md) · [Сайт](https://aliro.mayday.software/) ·
[Публичные исходники](https://github.com/ilia-ae/aliro-mayday/tree/main/aliro-site)

Angular 21 SPA размещена через Cloudflare Workers Static Assets. Сайт описывает
проверенный объём прототипа: прежний ключ iPhone владельца прошёл проверку
обновлённой прошивки 15 октября 2026; тесты на компьютере проверяют изменения
протокола и политики. Samsung/Google Wallet, отзыв на устройстве с отдельным
тестовым ключом, физическое реле и сертификация требуют отдельного подтверждения. Публикация кода не доказывает совместимость.

## Фото демо-стенда

На первом экране показана одна фотография сверху, без переключателя ракурсов
и подписи с именем автора под изображением. Прозрачные PNG и облегчённые WebP
находятся в `frontend/public/images/`. Подпись и альтернативный текст переведены
на оба языка. Фото обработано: IP скрыт, внешние провода убраны. Для подключения
нужна отдельная электрическая схема.

## Веб-интерфейс контроллера

Настоящая панель Svelte встроена в главную страницу сразу под фото стенда:
в ней используются демоданные, а отдельная ссылка открывает панель в новой вкладке.
Раскрываемая галерея сохраняет шесть снимков:
обзор, MQTT, действия, системные настройки, OTA и журнал. Кнопки разделов
и стрелки переключают картинки; каждую можно открыть в полном размере.
Все снимки содержат явно обозначенные демоданные. Это не проверка подключённого контроллера.
[Инструкция локального запуска и отладки](../docs/controller-ui-debug.ru.md)
описывает `bun run debug`; контроллер и ESP-IDF не нужны.

## Анимация и подтверждение снимка

В NFC-разделе есть анимация телефона, считывателя и двери с запуском по кнопке
и поддержкой уменьшения движения. Ограничение физического выхода указано рядом.
Анимация связана с исходами примеров ключей и журналом панели через браузерный
канал с проверкой origin, окна и ID. К физическому устройству она не обращается.

Ссылки на код и документацию отделены от лицензии. Карточка депонирования
показывает данные существующего пакета от 15 октября и ссылается на
[deposit.mayday](https://deposit.mayday.software/). Исходные байты подтверждений
и ожидающий статус Bitcoin сохранены. SVG-карточки EN/RU служат иллюстрацией.

В шапке панели показан ID контроллера. Обычная сборка использует существующий
Reader ID и тоже получает диагностику; кнопки симуляции доступны только в демо.
Telegram не подключён.

## Исходники и публикация

Основные публичные исходники — `aliro-site/` в `ilia-ae/aliro-mayday`.
Cloudflare Workers Build сейчас следит за отдельным приватным зеркалом
`ilia-ae/aliro-mayday-software`. Изменение монорепозитория само по себе не
публикует сайт. Перенесите в зеркало только исходники сайта и после проверки
отправьте изменения в его `main`. Не переносите локальные секреты, прошивку,
NVS, резервные копии контроллера, результаты сборки или каталоги зависимостей.

Subtree-помощники исходного рабочего каталога зависят от его приватной истории
Git; клон публичного снимка не использует их для публикации.

## Сборка и проверки в браузере

Проверена среда **Node 24.19.0**. Из каталога сайта:

```sh
cd frontend
npm ci
npm run build
npx playwright install chromium --only-shell
npx playwright test
```

Полный браузерный набор: **111 успешных тестов**, **5 явных пропусков**.
После последних правок текста дополнительно проверены ссылки на код и
переключение языка. Эти тесты проверяют сайт, а не замок и кошелёк.

`frontend/dist/aliro-mayday-software/browser` создаётся локально. Скрипты
корневого package управляют Angular-сборкой и Wrangler. Подключённая сборка
Cloudflare выполняет `npm install && npm run build`, затем `npx wrangler deploy`.
Настройте доступ к хостингу локально или в Cloudflare.

## Структура и языки

- `frontend/src/app/pages/landing/landing.ts`: страница и ссылки на исходники.
- `frontend/public/i18n/en.json` и `ru.json`: соответствующие тексты EN/RU.
- `frontend/e2e/`: браузерные проверки, включая ссылки и актуальный статус.
- `worker/src/index.ts` и `wrangler.toml`: выдача файлов и параметры хостинга.

В Git документация по умолчанию английская, русский перевод — `.ru.md`.
Сайт сохраняет выбор пользователя, затем учитывает язык браузера; запасной язык
остаётся русским. Обе версии ведут на соответствующие инструкции и схему
подключения. Выбор темы, QR-публикация и офлайн-кэш сохраняются.

## Сборка живого демо

`npm run build` во frontend сначала собирает настоящую панель из
`aliro-esp32/data` в отдельном режиме `web-demo`. В публичном монорепозитории
этот каталог находится рядом с `aliro-site`; зеркало публикации хранит копию
того же каталога в своём корне, вместе с `scripts/controller-ui-*.mjs`
и `scripts/debug-controller-ui.mjs`. Копировать нужно только исходники панели,
её `bun.lock`, конфигурацию и лицензии; без node_modules, .router и dist.

Сборщик использует Bun 1.3.13 по замороженному lock-файлу. Если этой версии
нет на хостинге, запускает официальный закреплённый пакет через npm exec.
Ресурсы `frontend/public/demo/` генерируются, не коммитятся и копируются Angular
в `/demo/`. Точка входа — `/demo/index.html`; переходы между разделами используют hash.
Демо исключено из Angular-навигации service worker. Его CSP запрещает сеть;
ответы API и события генерируются в браузере, команды устройства отклоняются.
Лицензионные тексты поставляются рядом в `/demo/NOTICES.txt`.
Обычная сборка панели для прошивки сохраняет прежний режим и не включает адаптер демо.

## Safari и service worker

Сохраните `html_handling = "none"` и
`not_found_handling = "single-page-application"` в `wrangler.toml`.
Перенаправление `/index.html` на `/` может зациклить Safari на сохранённом
перенаправлении при навигации через Angular service worker.

Версия запросов переводов вычисляется из содержимого EN/RU перед сборкой и
запуском разработки; `frontend/src/content-version.ts` не редактируется и не
публикуется. Service worker загружает целиком новую версию приложения/переводов
и перезагружает открытую страницу по событию `VERSION_READY`. Проверка выполняется
при возврате во вкладку, восстановлении сети и раз в минуту, пока страница видима.
Навигация предпочитает сеть; сохранённая версия доступна офлайн. HTML, переводы и
управляющие файлы worker получают заголовки повторной проверки. Вкладке с кодом
до этого исправления может потребоваться обычная перезагрузка для получения
нового обработчика обновлений.

Браузерный тест воспроизводит настоящее обновление service worker: сохраняет
прежнюю страницу в кэш, меняет manifest/переводы на сервере и проверяет обновление
открытой страницы без очистки данных браузера, с сохранением языка и URL.
`ALIRO_TEST_PORT` позволяет выбрать отдельный порт для тестов.

SSR отсутствует. Социальные роботы без JavaScript получают статические русские
метаданные; в браузере метаданные следуют выбранному языку. Лицензии компонентов
сохраняются; публичность исходников не делает весь код OSI Open Source.
